### Measurement Calibration Note
Measurements use relative amplitude scaling from standard microphone input. 
This provides accurate frequency identification and comparative analysis between 
locations. Absolute sound pressure levels (dB SPL) would require professional 
sound level meter calibration, recommended for formal compliance verification.
